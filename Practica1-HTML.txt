Ejercitación 1 - Responder el siguiente cuestionario
1. Qué es HTML, cuando fue creado, cuáles fueron las distintas versiones y cuál es la última?
HTML (HyperText Markup Language) es un lenguaje de marcado que se utiliza para la creación de paginas web. Es un estándar a cargo del World Wide Web Consortium que se impuso para la visualización de las mismas a nivel mundial, por lo que todos los navegadores lo adoptaron. Fue creado por Tim Berners-Lee en 1991, con el objetivo de compartir documentos científicos a través de la World Wide Web.
Versiones de HTML:
- HTML 	1.0 (1991): Fue la primera versión de HTML, creada por Tim Berners-Lee. Permitía crear páginas web muy simples con texto, títulos y 	enlaces. 	
- HTML 	2.0 (1995): Fue la primera versión oficial estandarizada. Incorporó 	formularios y mejoró la compatibilidad entre navegadores. 	
- HTML 	3.2 (1997): Añadió nuevas funcionalidades como tablas, applets de Java y mejoras en el formato del texto, permitiendo crear páginas más 	completas. 	
- HTML 	4.0 (1997): Introdujo importantes avances como la integración con CSS para separar el contenido del diseño, soporte para scripts (JavaScript), mejoras en accesibilidad e internacionalización. 		
- HTML 	4.01 (1999): 	Fue una revisión de HTML 4.0 que corrigió errores y mejoró la especificación. Se utilizó durante muchos años como estándar 	para el desarrollo web. 		
- XHTML 1.0 (2000): 	Fue una versión de HTML basada en XML, con reglas de escritura más estrictas. Su objetivo era lograr un código más ordenado y 	compatible. 	
- HTML5 (2014): Incorporó etiquetas semánticas como <header>, <section> y <footer>, soporte nativo para audio y video, gráficos mediante <canvas>, formularios mejorados y nuevas APIs para desarrollar aplicaciones 	web modernas. Es la versión vigente y continúa actualizándose como un Living Standard, es decir, un estándar que evoluciona de forma continua sin cambiar de nombre.

2. ¿Cuáles son los principios básicos que el W3C recomienda seguir para la creación de documentos con HTML?
Los principios básicos de diseño que recomienda el W3C para la creación de documentos con HTML son:
- Separar la estructura de la presentación: HTML debe utilizarse para definir la 	estructura y el significado del contenido, mientras que la apariencia (colores, fuentes, diseño, etc.) debe definirse mediante hojas de estilo (CSS). Esta separación facilita el mantenimiento y la adaptación del documento a distintos dispositivos. 	
- Considerar la accesibilidad universal: Los documentos deben ser accesibles para todos los usuarios, incluidas las personas con discapacidad. Además, deben poder visualizarse correctamente en diferentes navegadores, dispositivos y tecnologías de asistencia.
- Facilitar el procesamiento por parte de los navegadores: Los documentos 	deben estar bien estructurados para que los navegadores puedan 	interpretarlos y mostrarlos de manera eficiente, por ejemplo, diseñando correctamente las tablas y utilizando un código HTML válido. 

3. En las Especificaciones de HTML, ¿cuándo un elemento o atributo se considera desaprobado? ¿y obsoleto?
Un elemento o atributo se considera desaprobado (deprecated) cuando su uso ya no es recomendado porque existe una alternativa mejor o más moderna. Aunque todavía puede ser reconocido por los navegadores para mantener la compatibilidad con páginas antiguas, se aconseja no utilizarlo en desarrollos nuevos. En cambio, un elemento o atributo se considera obsoleto (obsolete) cuando ya no forma parte del estándar vigente y no debe utilizarse, ya que puede dejar de ser compatible en futuras versiones de los navegadores.

4. Qué es el DTD y cuáles son los posibles DTDs contemplados en la especificación de HTML 4.01?
El DTD (Document Type Definition) era un conjunto de reglas que definía la estructura y los elementos permitidos en un documento HTML. En HTML 4.01 existían tres tipos de DTD: Strict, que permitía únicamente los elementos recomendados; Transitional, que además admitía elementos desaprobados para facilitar la compatibilidad con versiones anteriores; y Frameset, que incorporaba soporte para el uso de marcos (frames). En HTML5 ya no se utilizan DTDs, sino una declaración mucho más simple: <!DOCTYPE html>.

5. ¿Qué son los metadatos y cómo se especifican en HTML?
Los metadatos son datos que describen información sobre una página web, como el autor, la descripción, las palabras clave, la codificación de caracteres o la configuración de la visualización en dispositivos móviles. No son visibles para el usuario, pero son utilizados por los navegadores, los motores de búsqueda y otras aplicaciones. En HTML se especifican dentro del elemento <head>, principalmente mediante la etiqueta <meta> , aunque también forman parte de los metadatos elementos como <title>, <link> y <base>.
